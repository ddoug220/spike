## Agent skills

### Issue tracker

Issues and PRDs are tracked in GitHub Issues. External pull requests are not a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the standard five-role triage vocabulary. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repository. See `docs/agents/domain.md`.

### Firebase

Use the official Firebase plugin's agent skills for Firebase work. Keep its marketplace and installed plugin current. Validate Firestore rule changes with `npm run test:rules` before deploying them to the app's Firebase project, `volleyballdb-9223f`. See the Firebase Security Rules section in `README.md` for setup and deployment commands.
