# Prioritize tablet landscape for live scoring

Live Court keeps the complete scoring loop visible without page scrolling at 1024 × 768 in landscape orientation. This layout lets an operator select a player, record an outcome, and undo an action while following live play.

Narrower portrait screens use one vertical column. Operators can scroll between the court and scoring controls without clipped controls, overlapping content, or horizontal overflow. Phone support does not require the complete scoring loop to fit without vertical scrolling.
