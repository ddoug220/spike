# Domain Docs

Spike uses a single domain context.

## Before exploring

- Read `CONTEXT.md` at the repository root when it exists.
- Read relevant decisions under `docs/adr/` when they exist.
- If either location is absent, continue silently. Domain-modeling skills create documents only when real terminology or decisions need to be recorded.

## Vocabulary

Use terms as defined in `CONTEXT.md` in issues, plans, tests, and code. Do not replace defined terms with new synonyms.

If a required concept is missing, first determine whether the new term is necessary. Use `/domain-modeling` to record a real vocabulary gap.

## Architectural decisions

Surface any conflict with an existing architectural decision. Do not silently override it.
